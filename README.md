# Forge FL IntelliJ Plugin

This is a starter IntelliJ plugin for the FL language described in `docs/LANGUAGE.md`.

## Features

- `.fl` file type support
- syntax highlighting for words, numbers, strings, comments, and booleans
- line comments using `\`
- block comments using `(...)`
- color settings page for FL syntax colors

## Run locally

```bash
./gradlew runIde
```

## Build

```bash
./gradlew build
```
